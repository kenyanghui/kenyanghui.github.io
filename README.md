# Loong 玄龙 · 官网（www.aibay.asia）

Loong AI 软件工程底座 + 企业定制手机交付的官方网站。

- 站点：https://www.aibay.asia
- 托管：GitHub Pages（本仓库 `main` 分支）
- DNS：`www.aibay.asia` → CNAME `kenyanghui.github.io`（DNSPod）

## 结构

```
index.html        单页官网（FDE 伙伴视角）
css/style.css     样式（品牌：玄夜 #0D1526 · 晨曦橙渐变 #EF6834→#FBD555 · 晴空蓝 #0092D4）
js/main.js        交互（滚动显现 / 数字动画 / 移动端菜单）
assets/           Loong 企业 VI 定稿资产（logo 全套 / favicon / lockup）
CNAME             www.aibay.asia
```
